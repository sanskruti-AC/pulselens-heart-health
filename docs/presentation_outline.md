# Suggested presentation outline
1. **Introduction:** Why structured data classification is useful for learning analytics.
2. **Problem statement:** Explore the relationship between 13 encoded features and a binary dataset label.
3. **Dataset:** 1,025 rows, 13 inputs, target; mention zero missing cells and duplicate concern.
4. **Methodology:** Audit → split → preprocess → train models → evaluate → web interface.
5. **Algorithms:** Logistic Regression, Decision Tree, Random Forest and RBF SVM.
6. **Evaluation:** Accuracy, precision, recall, F1 and ROC-AUC; discuss why accuracy alone is insufficient.
7. **Web application:** Enter sample values, calculate an educational score, view metrics.
8. **Limitations:** Duplicate rows, unknown provenance unless verified, no external validation, not a diagnostic tool.
9. **Conclusion and future work:** Deduplication sensitivity study, cross-validation, calibration, subgroup analysis.
